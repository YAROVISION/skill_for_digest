# Skill: Manual Document Segmentation

**Target File**: Daigest_07_2025

## Prompts Guidance
- Ознакою для розділення сегментів є нумерація справ (1.1, 4.1 тощо) на початку рядка.
- Кожен сегмент повинен починатись з відповідного номера.
- Закінчуватися сегмент повинен безпосередньо перед початком наступного номера або в кінці відповідного розділу.
- Один сегмент = Одна справа = Один JSON.
