# План реалізації: Ротатор провайдерів LLM (Безкоштовний стек)

Цей план описує впровадження системи ротації провайдерів для використання безкоштовних рівнів Cerebras, SambaNova та Groq. Система автоматично перемикатиметься на наступного доступного провайдера, якщо будуть досягнуті ліміти швидкості (rate limits), що забезпечить максимальний час безвідмовної роботи та економічну ефективність.

## Запропоновані зміни

### [НОВИЙ] [llm_rotator.py](file:///Users/kostantinkrivula/Desktop/sqlbase/skill_for_digest/agents/llm_rotator.py)

Створити окремий клас для обробки логіки ротації. Цей клас буде використовувати бібліотеку Python `openai` (сумісну з усіма трьома провайдерами) для керування викликами та повторними спробами.

- **Конфігурація провайдерів**:
    - **Groq**: `https://api.groq.com/openai/v1` (Модель: `llama-3.3-70b-versatile`)
    - **Cerebras**: `https://api.cerebras.ai/v1` (Модель: `qwen2.5-72b` або `qwen3-32b`)
    - **SambaNova**: `https://api.sambanova.ai/v1` (Модель: `DeepSeek-R1-Distill-Llama-70B`)
- **Логіка**:
    - Реалізувати метод `chat_completion`, який приймає запит (prompt) та додаткові налаштування.
    - Спробувати провайдерів у визначеному порядку (наприклад, Groq -> Cerebras -> SambaNova).
    - Перехоплювати помилки `RateLimitError` або загальні `Exception` і переходити до наступного провайдера.
    - Логувати, який провайдер використовується в даний момент для прозорості.
