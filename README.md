# `pdf_md` — Трубопровід обробки юридичних документів

Цей проект автоматизує збір аналітичних оглядів і дайджестів з сайту Верховного Суду України у форматі PDF, їх збереження в MinIO, конвертацію у формат Markdown та керування документами через веб-інтерфейс.

---

## 1. Скрапінг та збір документів (`agents/scrape_of_courtsite_pdfs.py`)

Скрипт призначений для автоматичного моніторингу та завантаження аналітичних оглядів з сайту Верховного Суду України.

### **Функції та правила скрапінгу:**

- **Моніторинг**: Парсить сторінку [Аналізу ВСУ](https://supreme.court.gov.ua/supreme/pokazniki-diyalnosti/analiz/) на предмет нових PDF-посилань.
- **Уникнення дублікатів**: Перевіряє наявність файлу локально в `agents/pdfs/` та в реєстрі `agents/lists/list_of_pdfs.md`. Якщо файл уже є, він пропускається.
- **Нормалізація**: Очищає імена файлів від технічних префіксів, транслітерує кирилицю та нормалізує пробіли для коректного збереження.
- **Завантаження та журнал**: Зберігає PDF-документи локально в `agents/pdfs/`, завантажує в MinIO у папку `pdfs/` та веде журнал нових скачувань із датою, часом і розміром у файлі `agents/lists/download_history.md`.

### **Команди запуску скрапінгу:**

```bash
# Запуск у робочому режимі (завантаження та оновлення списку й журналу)
.venv/bin/python agents/scrape_of_courtsite_pdfs.py

# Запуск у режимі тестування (без завантаження)
DRY_RUN=true .venv/bin/python agents/scrape_of_courtsite_pdfs.py
```

## 2. Конвертація PDF у Markdown (`agents/convert_pdfs_to_md.py`)

Цей модуль відповідає за перетворення бінарних PDF-файлів у текстовий формат Markdown.

### **Функції та правила конвертації:**

- **Розумна обробка**: Порівнює вміст папок `pdfs/` та `markdown/` у MinIO, конвертуючи лише ті файли, які ще не мають відповідної Markdown-копії.
- **Якісна конвертація**: Використовує бібліотеку `pymupdf4llm` для збереження структури тексту та таблиць.
- **Транслітерація**: Автоматично перетворює кириличні назви файлів у латиницю для стабільної роботи системних шляхів.
- **Структура збереження**: Результат зберігається у `agents/markdown/{назва_документа}/{назва_документа}.md` та в MinIO (`markdown/{назва_документа}/{назва_документа}.md`).

### **Команди запуску конвертації:**

```bash
# Конвертувати всі нові PDF-файли
.venv/bin/python agents/convert_pdfs_to_md.py

# Конвертувати конкретний файл за назвою (або частиною назви)
.venv/bin/python agents/convert_pdfs_to_md.py Oglyad_ESPL_11_2024
```

## 3. Графічний інтерфейс користувача (`dashboard/`)

Для зручного моніторингу, оновлення та перегляду документів розроблено веб-інтерфейс на базі Streamlit (`pdf_md`).

### **Функції веб-інтерфейсу:**

- **📋 Зведена таблиця наявності файлів**:
  - Відображає всі документи в єдиній таблиці з нумерацією рядків та позначками **Так / Ні** для колонок `agents/pdfs`, `MinIO (pdfs/)` та `agents/markdown`.
  - Записи з позначкою **Ні** автоматично піднімаються нагору таблиці, а під назвою кожної колонки відображаються лічильники `Так` і `Ні`.
  - Пошук файлів за назвою в реальному часі.
  - Назви файлів є активними посиланнями на локальні PDF з `agents/pdfs/`, а позначки **Так** у колонці `agents/markdown` відкривають відповідний `.md` файл у вбудованому редакторі.
- **🔄 Оновлення з сайту ВСУ**:
  - Картка-кнопка `PDF у agents/pdfs` запускає `agents/scrape_of_courtsite_pdfs.py` у фоновому режимі для перевірки та завантаження нових файлів.
  - Розгортаний блок нижче відображає журнал скачувань із `agents/lists/download_history.md`.
- **📝 Вбудований редактор і переглядач Markdown**:
  - Двопанельний режим: редактор тексту зліва (із збереженням змін на диск та скачуванням `.md`) і живий попередній перегляд справа.
- **🎨 Теми оформлення**:
  - Перемикач тем у правому боці хедера у вигляді 4 кольорових індикаторів: **Лате**, **Сланець**, **Літо**, **Місто**.

### **Команди для запуску дашборду:**

**macOS / Linux:**

```bash
.venv/bin/python -m streamlit run dashboard/app.py
```

**Windows (PowerShell або CMD):**

```powershell
.venv\Scripts\python.exe -m streamlit run dashboard/app.py
```

Адреса за замовчуванням: **<http://localhost:8501>**.

## ⚙️ Загальні вимоги для всього проекту

1. **Файл конфігурації**: Переконайтеся, що `.env.local` містить доступи до MinIO (`MINIO_ENDPOINT`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_BUCKET`).
2. **Залежності**: Усі бібліотеки описані в `requirements.txt`. Встановіть їх у віртуальне середовище командою:

   ```bash
   .venv/bin/pip install -r requirements.txt
   ```
