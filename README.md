# Юридичний AI-Агент: Трубопровід обробки документів

Цей проект являє собою повний цикл автоматизації обробки юридичних документів: від скрапінгу з офіційних сайтів до інтелектуальної сегментації статей за допомогою ШІ.

---

## 1. Скрапінг та збір документів (`scrape_of_courtsite_pdfs.py`)

Скрипт призначений для автоматичного моніторингу та завантаження аналітичних оглядів з сайту Верховного Суду України.

### **Основні функції та правила:**
- **Моніторинг**: Парсить сторінку [Аналізу ВСУ](https://supreme.court.gov.ua/supreme/pokazniki-diyalnosti/analiz/) на предмет нових PDF-посилань.
- **Уникнення дублікатів**: Перед завантаженням перевіряє файл у локальному реєстрі `agents/lists/list_of_pdfs.md`. Якщо файл уже є в списку, він ігнорується.
- **Нормалізація**: Очищає імена файлів від технічних префіксів та нормалізує їх для коректного збереження.
- **Завантаження**: Зберігає документи у MinIO у папку `pdfs/`.

### **Команди для запуску:**
```bash
# Запуск у робочому режимі (завантаження та оновлення списку)
python3 agents/scrape_of_courtsite_pdfs.py

# Запуск у режимі тестування (без завантаження)
DRY_RUN=true python3 agents/scrape_of_courtsite_pdfs.py
```

## 2. Конвертація PDF у Markdown (`convert_pdfs_to_md.py`)

Цей модуль відповідає за перетворення бінарних PDF-файлів у текстовий формат Markdown, придатний для обробки штучним інтелектом.

### **Основні функції та правила:**
- **Розумна обробка**: Скрипт автоматично порівнює вміст папок `pdfs/` та `markdown/` у MinIO. Він конвертує лише ті файли, які ще не мають відповідної Markdown-копії.
- **Якісна конвертація**: Використовує бібліотеку `pymupdf4llm` для збереження структури тексту та таблиць.
- **Транслітерація**: Автоматично перетворює кириличні назви файлів у латиницю для стабільної роботи системних шляхів.
- **Структура збереження**: Результат зберігається за шляхом `markdown/{назва_документа}/{назва_документа}.md`.

### **Команди для запуску:**
```bash
# Конвертувати всі нові PDF-файли
python3 agents/convert_pdfs_to_md.py

# Конвертувати конкретний файл за назвою (або частиною назви)
python3 agents/convert_pdfs_to_md.py Oglyad_ESPL_11_2024
```

## 3. Сегментація та структурування статей (`run_agent.py`)

Фінальний етап, на якому агент "Гермес" розбиває великі Markdown-файли на окремі юридичні позиції та перетворює їх на структурований JSON.

### **Основні функції та правила:**
- **Використання Skills**: Для максимально точної сегментації агент використовує файли-скіли з папки `agents/skills_for_markdownfiles/`. Вони містять точні маркери початку та кінця кожної справи.
- **AI-Аналіз**: Використовує модель `qwen2.5-coder:14b` (через Ollama) для виділення тези, номера справи, дати та категорії.
- **Збереження результату**: Структуровані дані завантажуються у MinIO у папку `structured/{slug}/` та зберігаються локально у `documents/structured/`.

### **Команди для запуску:**
```bash
# Запуск повної сегментації всіх нових документів
python3 run_agent.py

# Обробка конкретного документа
python3 run_agent.py 1775151780288_Oglyad_ESPL_09_2024
```

### **Як користуватись "скілами":**
1. Створіть файл `.md` у `agents/skills_for_markdownfiles/`.
2. Вкажіть **Target File** (назву документа).
3. Опишіть сегменти:
   ```markdown
   ### [ID_Статті]
   - **Category**: Категорія
   - **Start**: Текст початку справи
   - **End**: Текст кінця справи (або початок наступної)
   ```
